# Spherical outflow into vacuum

This example exercises spherical outflow into a vacuum and the solver's
low-density handling near the expanding front.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/OutflowSphVacuum1D`
4. `python outflow_sph_vacuum1d.py --config outflow_sph_vacuum1d.yaml`

The run produces the configured snapshots and diagnostic figure.
