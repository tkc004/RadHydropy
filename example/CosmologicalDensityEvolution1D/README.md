# Cosmological density evolution

This example tests the analytic evolution of a homogeneous gas density in an
expanding Einstein–de Sitter universe.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/CosmologicalDensityEvolution1D`
4. `python cosmological_density_evolution1d.py`

The default YAML file is `cosmological_density_evolution1d.yaml`; results are
written to the paths selected by that configuration.
