# EdS and LCDM cosmological top-hat comparison

This example integrates a dark-matter top-hat perturbation in both
Einstein–de Sitter and Lambda-CDM cosmologies and compares turnaround and
radius evolution with reference calculations.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/CosmologicalTopHatEdSLambdaCDM1D`
4. `python cosmological_tophat_eds_lcdm.py`

The script uses the accompanying correlation YAML and writes comparison
outputs below this example's `outputs/` directory.
