# 20 pc dynamic Stromgren sphere with photoheating

This example models a photoheated, expanding H II region in a 20 pc spherical
domain and records its ionization-front and thermal evolution.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/DynamicStromgrenSpherePhotoheating20pc1D`
4. `python dynamic_stromgren_sphere_photoheating20pc1d.py --config dynamic_stromgren_sphere_photoheating20pc1d.yaml`

Inspect the configured output directory for HDF5 snapshots and plots.
