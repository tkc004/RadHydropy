# Spherical hydrostatic equilibrium around a point mass

This example tests a spherical gas atmosphere balanced against the gravity of a
central point mass.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/HydrostaticEquilibriumSphericalPointMass1D`
4. `python hydrostatic_equilibrium_spherical_point_mass1d.py --config hydrostatic_equilibrium_spherical_point_mass1d.yaml`

Results are saved under the output path defined by the YAML configuration.
