# Planar outflow

This example tests a one-dimensional outflow boundary in a planar domain.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/Outflow1d`
4. `python outflow1d.py --config Outflow1d.yaml`

The configured output directory receives the snapshots and diagnostic plot.
