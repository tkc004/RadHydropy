# Spherical outflow

This example tests spherical outflow and compares the numerical solution with
the accompanying analytic spherical outflow calculation.

1. `cd RadHydropy`
2. `python -m pip install -e ".[test,docs]"`
3. `cd example/OutflowSph1d`
4. `python outflow_sph1d.py --config OutflowSph1d.yaml`

Outputs are written according to the selected YAML configuration.
