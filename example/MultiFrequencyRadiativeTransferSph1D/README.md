# Multifrequency radiative transfer: static H II region

This example evolves a static, uniform pure-hydrogen medium around a central
ionizing source. It combines spherical long-characteristics transport with
hydrogen photoionization, photoheating, recombination, collisional ionization,
and temperature evolution.

The example uses five photon groups:

```text
[13.6, 24.6, 35.5, 54.4, 75.0, 50000] eV
```

The spectrum is read at RadHydropy startup from the HDF5 file configured by
`radiation_spectrum_filename`. The current default file is generated by
`tools/radiation_spectrum_generator` and contains the group edges, photon
energies, source emission rates, H I cross sections, photoheating energies,
and spectrum metadata.

## Run

From this directory:

```bash
python multifrequency_radiative_transfer_sph1d.py \
  --config multifrequency_radiative_transfer_sph1d.yaml
```

The generated spectrum can be recreated from the repository root with:

```bash
python tools/radiation_spectrum_generator/generate_radiation_spectrum.py
```

To use another spectrum, change `radiation_spectrum_filename` in the YAML.
The path is resolved relative to the YAML file.

## Source normalization

The HDF5 file stores the relative source spectrum. The optional YAML setting

```yaml
radiation_spectrum_total_photon_rate:
  value: 5.0e48
  unit: 1/s
```

rescales all ionizing groups to the requested total photon rate while
preserving their relative spectrum. If it is omitted, the normalization in
the HDF5 file is used unchanged.

The first entry in `star_emission_rates` is the non-ionizing placeholder. The
remaining entries correspond to the ionizing groups.

## Runtime configuration

The YAML uses:

- `hydrogen_alpha_B: null` and `hydrogen_beta: null` to select the built-in
  temperature-dependent H recombination and collisional-ionization rates.
- `hydrogen_collisional_ionization: true`.
- `hydrogen_thermal_coupling: true` for photoheating and cooling.
- `final_time = 100 Myr` and `n_H = 10^-3 cm^-3`.
- 512 spherical cells over 10 kpc.

`Par` loads and validates the spectrum during startup. The HDF5 spectrum is
also reloaded after an initial-condition file is read so that units are not
lost when parameters are restored from the HDF5 header.

## Output

The run writes:

- `InitialCondition.hdf5` — generated initial state.
- `Output_000.hdf5` — final state.
- `MultiFrequencyRadiativeTransferSph1D.jpg` — radial profiles.

The figure contains neutral hydrogen fraction, temperature, and photon
number density for each radiation group.

## Reference profiles

The reference files are the multifrequency TT1D profiles from the cited
Stromgren-sphere comparison:

- `TTT1D_Stromgren100Myr.txt` — radius normalized by `r_s = 5.4 kpc` and
  `log10(T/K)`.
- `xTT1D_Stromgren100Myr.txt` — radius normalized by `r_s = 5.4 kpc` and
  `log10(x_HI)`.

The plotting code converts the second column back with `10**value` before
overlaying the references.

The current chemistry network is pure hydrogen, so the H I datasets are used
from the H/He spectrum file while the He I and He II datasets are retained for
future helium chemistry.
