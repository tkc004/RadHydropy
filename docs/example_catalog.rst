Complete Example Catalog
========================

This page is the complete catalog of example directories currently present
under ``example/``. It is intentionally directory-based: not every example
has a dedicated page in the documentation, and some directories contain
multiple runners or configuration variants.

Run commands from the selected example directory. Consult its ``README``
when present before launching a long run, because some examples require
generated tables, external data, or a particular configuration variant.
