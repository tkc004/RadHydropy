Example Matrix
==============

Use this matrix to choose a small, focused example. Run commands from the
listed example directory; this is important because the runners import local
``tools.py`` helpers and resolve output paths relative to the working
directory.

Core solver and verification examples
--------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 21 27 27 15 18

   * - Example
     - What it demonstrates
     - Run command
     - Typical output
     - Prerequisites
   * - ``SodShock1D``
     - Basic Cartesian shock-tube evolution and analytic comparison.
     - ``python sodshock1d.py``
     - ``Output_*.hdf5`` and ``SodShock1D.jpg``
     - None beyond the base installation.
   * - ``Advection1D``
     - Cartesian advection and profile transport.
     - ``python advection1d.py``
     - Snapshot files and an advection figure.
     - None beyond the base installation.
   * - ``AdvectionSph1D``
     - Spherical advection with the positivity limiter enabled.
     - ``python advection_sph1d.py``
     - ``AdvectionSph1D.jpg``
     - None beyond the base installation.
   * - ``SphericalConvergingShock1D``
     - Spherical convergence, reflecting boundaries, dual energy, and shock heating.
     - ``python spherical_converging_shock1d.py --config spherical_converging_shock1d.yaml``
     - ``SphericalConvergingShock1D.jpg``
     - None; the YAML contains the validated benchmark settings.
   * - ``NohSphericalImplosion1D``
     - Strong spherical implosion and resolution/convergence behavior.
     - ``python noh_spherical_implosion1d.py``
     - Profile figures and convergence diagnostics.
     - None beyond the base installation.

Thermo-chemistry and radiation examples
----------------------------------------

.. list-table::
   :header-rows: 1
   :widths: 21 27 27 15 18

   * - Example
     - What it demonstrates
     - Run command
     - Typical output
     - Prerequisites
   * - ``UniformEdSThermochemistry1D``
     - Compton and atomic thermochemistry in an expanding background.
     - ``python uniform_eds_thermochemistry1d.py``
     - Thermal-history figures and HDF5 snapshots.
     - None; uses the bundled thermochemistry configuration.
   * - ``HIIRegionExpansion1D``
     - Hydrodynamic H II-region expansion with early/late C²-Ray variants.
     - ``python early_hii_region_expansion1d.py --config early_hii_region_expansion1d.yaml``
     - Ionization-front and density figures.

   * - ``StaticStromgrenC2RayComparison``
     - Comparison of instantaneous and causal ionization-front updates.
     - ``python static_stromgren_c2ray_comparison.py``
     - Comparison figure and CSV diagnostics.
     - None; comparison inputs are generated by the runner.
   * - ``MultiFrequencyRadiativeTransferSph1D_HHe_30000K_100Myr``
     - Five-group H/He transport, photoheating, and PIE evolution.
     - ``python multifrequency_radiative_transfer_sph1d_hhe_30000k_100myr.py``
     - ``Output_000.hdf5`` and PIE diagnostic figures.
     - Bundled H/He spectrum and thermo-chemistry tables.

Cosmology and dark matter examples
-----------------------------------

.. list-table::
   :header-rows: 1
   :widths: 21 27 27 15 18

   * - Example
     - What it demonstrates
     - Run command
     - Typical output
     - Prerequisites
   * - ``EinsteinDeSitterHomogeneous1D``
     - Homogeneous supercomoving expansion and representation conversion.
     - ``python einstein_de_sitter_homogeneous1d.py``

The cosmological correlation configurations are a larger workflow. Use the
dedicated :doc:`cosmological_virial_shock1d` page for prerequisites, generated
correlation tables, production configurations, and expected diagnostics.

Choosing a starting point
--------------------------

* Start with ``SodShock1D`` to verify installation and the basic runner.
* Use ``Advection1D`` or ``AdvectionSph1D`` for a small conservation/profile
  test.
* Use ``UniformEdSThermochemistry1D`` or ``HIIRegionExpansion1D`` when
  testing source terms.
* Use ``CosmologicalVirialShock1D`` only after the smaller examples work; its
  correlation-function inputs and generated diagnostics make it substantially
  more expensive.

For the complete inventory, including specialist analytic and reference
problems, see :doc:`examples`.
